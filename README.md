# Gym — мини-приложение

Мини-приложение Telegram для бота Gym: тренировка, прогресс, история.

- Это только страница: данных и ключей здесь нет.
- Данные приходят от того же бота, что отдал страницу (для разработки адрес бота можно задать `?api=…`).
- Каждый запрос подписан Telegram — бот проверяет, кто пишет.
- Страницу отдаёт сам бот: сборка (`npm run build`, папка `dist`) кладётся в папку `webapp/` бота.

## Запуск локально

```bash
npm install
npm run dev
```

Вне Telegram страница покажет «Открой приложение кнопкой в чате с ботом» — это нормально.

## Структура

| Папка | Что внутри |
|---|---|
| `src/lib` | Типы и форматирование |
| `src/data` | Запросы к боту и состояние |
| `src/ui` | Кнопки, карточки, графики |
| `src/platform/web` | Telegram WebApp и адресная строка |
| `src/features` | Экраны: главная, тренер (чат с ИИ), тренировка, отдых, финиш, прогресс, история, профиль и анкета, отзыв и удаление данных |
| `src/dev` | Макеты на выдуманных данных: `npm run dev`, затем `?mock=profile` или `?mock=chat` (в сборку не попадают) |
| `src/app` | Сборка экранов и вкладки |

## Постоянный адрес (worker/)

`worker/index.js` — воркер Cloudflare на https://gymbot.gymbot-f4ea8ac9.workers.dev (KV-привязка `GYM`).
Бот сообщает ему текущий адрес туннеля (`POST /__origin`), воркер пересылает туда все запросы.
Первый ключ бота запоминается; чтобы сменить компьютер с ботом — удалить ключ `key` в KV `gymbot`.
